 FIBER FAST — คู่มือขึ้นเว็บ Netlify (ฟรี)
═══════════════════════════════════════════════════

▶ วิธีขึ้นเว็บ (ง่ายสุด ไม่ต้องใช้ Git)

  1. เข้าเว็บ  https://app.netlify.com/drop
  2. สมัคร/ล็อกอินด้วย Email หรือ Google (ฟรี)
  3. ลาก "ทั้งโฟลเดอร์นี้" (หรือไฟล์ .zip) ไปวางในหน้าเว็บ
  4. เสร็จ! ได้ลิงก์เว็บ เช่น https://ชื่อสุ่ม.netlify.app
     - เปลี่ยนชื่อเว็บได้ที่ Site configuration → Change site name
     - ใส่โดเมนตัวเองได้ที่ Domain management (ฟรี HTTPS อัตโนมัติ)

▶ ฟอร์ม "ลงทะเบียน" ใช้งานยังไง

  - ฟอร์มใช้ระบบ Netlify Forms (แผนฟรี ได้ 100 ใบสมัคร/เดือน)
  - ทันทีที่ขึ้น Netlify แล้ว ฟอร์มจะทำงานเอง
  - ดูใบสมัครที่: เว็บ Netlify → เลือก Site ของคุณ → แท็บ "Forms"
  - ตั้งให้ส่งเข้าอีเมลได้ที่: Forms → Settings → Notifications

▶ จุดที่ควรแก้เป็นของคุณเอง (เปิดด้วย Notepad ก็แก้ได้)

  1. ชื่อแบรนด์ "FIBERFAST"
     → ค้นหาคำว่า FIBERFAST ในไฟล์ index.html แล้วเปลี่ยนทั้งหมด
  2. ราคา/ความเร็วแพ็กเกจ
     → ใน index.html มีคอมเมนต์บอกตำแหน่งว่า
       "✏️ แก้ชื่อ/ความเร็ว/ราคาแพ็กเกจได้ที่นี่"
     (ราคาในหน้าเว็บเป็นตัวอย่างตลาดทั่วไป ควรแก้ให้ตรงโปรโมชั่นจริงของคุณ)
  3. ลิงก์ LINE
     → ตั้งไว้แล้วเป็น https://line.me/ti/p/okGbiHWs0U ทุกปุ่ม
       ถ้าอยากเปลี่ยน ค้นหา "line.me/ti/p" ใน index.html แล้วแทนที่
  4. ข้อความ FAQ / จุดเด่น
     → แก้ได้ตรง ๆ ใน index.html (เป็น HTML ธรรมดา ไม่มีระบบ login)

▶ ไฟล์ในโฟลเดอร์

  index.html      — หน้าเว็บหลักทั้งหมด (ภาษาไทย)
  style.css       — ตกแต่งหน้าเว็บ
  script.js       — เมนูมือถือ, เอฟเฟกต์, ส่งฟอร์ม
  favicon.svg     — ไอคอนแท็บเบราว์เซอร์
  images/         — รูปที่สร้างด้วย AI (ใช้ได้ ไม่ละเมิดลิขสิทธิ์)

▶ หมายเหตุ

  - เว็บนี้เขียนเนื้อหาใหม่ทั้งหมด ไม่ได้ก็อปข้อความ/รูป/โลโก้จากเว็บผู้ให้บริการรายใด
    (การก็อปเว็บคนอื่นแบบเป๊ะ ๆ มาโฮสต์ ผิดลิขสิทธิ์ และ Netlify จะปิดเว็บให้)
  - ตัวเลข เช่น "ตอบไวทุกวัน" "นัดติดตั้งได้ในไม่กี่วัน" เป็นข้อความตัวอย่าง
    ควรปรับให้ตรงกับบริการจริงของคุณ
  - รองรับมือถือครบ ไม่มีระบบ login ตามที่ต้องการ
